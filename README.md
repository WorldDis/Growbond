# GROWBOND Website

Next.js (App Router) + TypeScript + Tailwind CSS.

## Setup (Windows 11)
1. Install Node.js LTS.
2. `npm install`
3. `npm run dev` -> http://localhost:3000

## Build
`npm run build && npm start`

## Deploy
Push to GitHub, import in Vercel, set domain growbond.in. Preserve GoDaddy Professional Email DNS records.
